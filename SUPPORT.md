# Support

## Before asking for help

Run:

```bash
./orchestra doctor
python3 scripts/public_safety_scan.py
```

Then search existing issues for the same error or platform.

## Where to ask

- Bugs: use the Bug Report issue form.
- Feature ideas: use the Feature Request form.
- New agents/backends/providers: use the Integration Request form.
- Security issues: follow `SECURITY.md`; do not post them publicly.

## Include useful evidence

Share your OS, Python version, Orchestra version/commit, Ollama version, installed local model names, the exact command, and sanitized error output.

Do not paste API keys, auth files, personal paths, phone numbers, chat IDs, or private repository content.
